# 天赋树

用 `/cultivation skilltree`（别名 `skills`）打开。天赋树是一张环形图：九条分支自中央徽记向外辐射，彼此相隔 40 度，每解锁一个节点，其所在的辐条便会亮起。画布可双向滚动，因此你能一路拖到最外环再拖回来。

## 天赋点

天赋点来自**境界提升**，而非反复刷怪：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `Points-Per-Advancement` | 1 | 每次阶段晋阶所授。 |
| `Points-Per-Breakthrough` | 2 | 突破至新境界时，在上一项之外**额外**再授。 |

一次失败的仪式会使你跌落一阶，并收回该阶段所授予的天赋点。若你已经花掉了它们，这笔欠账会一直背到你重新赚回为止。管理员可用 `/cultivation admin grantskillpoints` 直接发放。

## 九条分支

每条分支专精一项属性。枚举顺序即为环上顺序，且**相邻关系至关重要**：混合节点会向紧挨着它的分支借取属性。

| 分支 | 属性 | 数值类型 |
| --- | --- | --- |
| 体魄 | 生命上限 | 定值 |
| 韧性 | 屏息 | 定值 |
| 力道 | 伤害 % | 百分比 |
| 护体 | 减伤 % | 百分比 |
| 悟性 | 灵气获取 % | 百分比（独立档） |
| 和合 | 仪式速度 % | 百分比 |
| 疾行 | 移动速度 % | 百分比 |
| 耐力 | 体力 | 定值 |
| 灵识 | 法力 | 定值 |

生命、法力、体力与屏息是通过实体属性表施加的**定值加算**。百分比类属性则在其之外结算：伤害 % 与境界、种族一同叠入你的伤害倍率；灵气获取 % 作用于每一个灵气来源；仪式速度 % 进入晋阶／突破／炼器的时长公式；减伤 % 与本命护甲一同作用于受到的伤害；移动速度 % 则直接加在你的基础移速上。

## 节点层级与前置

每个节点都需先解锁其父节点。一条分支自中心笔直延伸至第 4 层，在第 5 层一分为二，第 7 层再度分叉，最终于唯一的第 8 层超脱节点重新汇合。

```mermaid
flowchart LR;
    T1["第1-4层<br/>本分支辐条"] --> F["第5层<br/>分叉 A / B"];
    F --> T6["第6层<br/>延续各自配对"];
    T6 --> T7["第7层<br/>再度分叉"];
    T7 --> T8["第8层 超脱<br/>双前置"];
```

第 1 至 4 层各携带**一项**加成，即本分支自身的属性。第 5、6、7 层为**混合节点**，各携带两项：本分支属性取较大值，外加相邻分支属性的一份较小值。分叉 A 向逆时针方向的相邻分支借取，分叉 B 向顺时针方向借取；第 6、7 层则以更大的数值延续其父节点的完全相同的配对。

| 层级 | 消耗 | 定值 主/次 | 百分比 主/次 |
| --- | --- | --- | --- |
| 1 - 4 | 各 1 点 | 10 / 20 / 35 / 55 | 3 / 5 / 8 / 12（悟性：4 / 7 / 10 / 14） |
| 5（分叉） | 2 | 55 / 30 | 7 / 4 |
| 6 | 2 | 80 / 45 | 10 / 6 |
| 7 | 3 | 110 / 60 | 12 / 7 |
| 8（超脱） | 4 | 见下 | 见下 |

某个数值取定值列还是百分比列，取决于**属性本身**而非分支 —— 一个体魄节点借取屏息时，两半都用定值；而它借取力道时，被借的那一半便用百分比。

一条完整分支为 **13 个节点、28 点**，因此九条分支尽数点满即为 **117 个节点、252 点**。深度专精是一项真正的取舍，而非水到渠成。

## 第八层 · 超脱

每条分支只以**一个**第 8 层节点收束，位置回到本分支自身的辐条上。它们是全树**仅有的双前置节点**：你必须同时持有辐条两侧的第 7 层节点（A2 与 B1），也就是说必须在分叉的两条支路上都下足投入，而不能只挑一边一路走到底。

每个超脱节点授予三种辅助属性之一，沿环轮转，因此每种属性各由三条分支承载：

| 超脱属性 | 数值 | 所属分支 |
| --- | --- | --- |
| 灵气消耗降低 % | 各 +8% | 体魄、护体、疾行 |
| 本命法宝经验 % | 各 +25% | 韧性、悟性、耐力 |
| 灵脉汲取半径 | 各 +1 圈区块 | 力道、和合、灵识 |

**灵气消耗降低**会按比例削减每次晋阶与突破所需的灵气，总量受 `Qi-Cost-Reduction-Cap-Percent`（默认 40%）钳制，以免境界提升的代价彻底崩塌。**本命法宝经验**倍增你所绑定装备获取的经验。**灵脉汲取半径**则在 `Spirit-Vein-Drain-Radius-Chunks` 之上，进一步扩大打坐可汲取的相邻区块圈数。

## 洗点

`/cultivation respec`（别名 `resetskillpoints`、`resetskills`）会清空你的天赋树，并退还所有已花费的点数。此功能默认开启，可用 `Respec-Enabled` 关闭，使流派成为永久抉择。

由**秘籍**传授的节点不消耗天赋点，因此不在退还之列，也会在洗点后原样保留 —— 读秘籍无法凭空造出天赋点，洗点也不会毁掉你已经消耗过的秘籍。

<Panel title="指令">
  | 指令 | 说明 | 权限 |
  | --- | --- | --- |
  | `/cultivation skilltree` | 打开环形天赋树。别名：`skills`。 | `cultivation` |
  | `/cultivation respec` | 退还全部已花费点数并清空天赋树。 | `cultivation` |
  | `/cultivation bonuses` | 列出当前作用于你的全部加成，含天赋树。 | `cultivation` |
  | `/cultivation admin grantskillpoints` | 为某玩家发放天赋点。 | `cultivation` |
</Panel>

天赋点发放、灵气消耗上限与洗点开关位于 `Cultivation/SkillTreeConfig.json` —— 详见[修炼配置](/zh/config-cultivation/)。
