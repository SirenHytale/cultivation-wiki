# 入门指南

先把模组装好，再用第一个小时熟悉那条一路通向炼虚的循环： 采气、坐下、突破。

## 安装

<CardGrid cols={2}>
  <Card title="客户端 / 单人" han="客">
    将 `Cultivation.jar` 放入：

    ```
    %appdata%\Hytale\UserData\Mods\
    ```
  </Card>

  <Card title="服务端" han="服">
    将 `Cultivation.jar` 放入服务端的：

    ```
    mods\
    ```
  </Card>
</CardGrid>

<Note kind="warn" title="务必先删除旧版">
  添加新版之前，请移除任何旧的 `Cultivation.jar`。 同时存在两份会产生冲突，服务端将无法正常启动。
</Note>

本模组**单人与多人皆可运行**。服务器上只需服务端装载即可运作，但未安装的玩家将看不到自定义菜单。

## 你的第一个小时

### 1. 打开信息面板

执行 `/cultivation hud`，屏幕角落会常驻一块面板，显示境界、阶段、灵气进度与当前仪式进度。 可在 `/cultivation settings` 中把它移到四角中的任意一处。

单独执行 `/cultivation` 会打开完整面板；`/cultivation info` 则把同样的数据打印到聊天栏。

### 2. 赚取第一笔灵气

两条途径，详见[聚灵采气](/zh/qi-gathering/)：

- **击杀生物**，有几率掉落灵核、玄核或神核。右键即可立即吸收。
- **打坐**，用 `/cultivation meditate` 汲取所在区块的天地灵气。

<Note kind="tip" title="双管齐下">
  在已经打坐的状态下吸核，可在其原本灵气之上额外获得加成。攒着核，等打坐时再一并吸收。
</Note>

### 3. 逐阶晋升

阶段晋阶（初期 → 中期 → 后期 → 巅峰）是短仪式 —— 阶梯底端仅需 8 秒 —— 且区块灵脉只需 **200**。灵气攒够并坐下，它便会自行发生。

### 4. 挺过第一次突破

从巅峰迈入下一重境界则截然不同：需要区块灵脉**不低于 750**、 一段 24 秒不被打断的仪式，以及在天劫雷落之时端坐不动的胆识。

<Note kind="warn" title="切勿起身">
  离开落座之处，或手动中断，都会**令你跌落一个阶段**并清空灵气。 突破雷劫确有致命之力。请满血入场，并在动手前先读一遍[境界与阶段](/zh/realms/)。
</Note>

## 随后开启的内容

| 解锁时机 | 体系 | 所得 |
| --- | --- | --- |
| <Chip>金丹</Chip> | 种族 | 人族、魔族或神族的一次性抉择，各有属性侧重 |
| 每次晋升 | 天赋树 | 九条分支的天赋点，晋阶 +1，突破 +3 |
| 可配置 | 大道 | 五行之环上的元素、随行止漂移的阴阳之衡，以及正魔两途 |
| 任意境界 | 本命法宝 | `/cultivation bind` 将武器或护甲与你相系，越用越强 |
| 任意境界 | 宗门 | 开宗立派、于龙脉设立大殿，终有一日为之开战 |

## 服主须知

模组中每一个数值都存放于分类清晰的 JSON 配置文件中 —— 没有任何写死的常量 —— 其中最常调整的那些，还能通过 `/cultivation admin` 在**游戏内实时修改**， 既不必编辑文件，也无需重启。

## 权限

| 权限节点 | 授予 |
| --- | --- |
| `cultivation` | 基础指令及全部面向玩家的子指令 |
| `cultivation.admin` | 全部 `/cultivation admin` 子指令与管理菜单 |
| `cultivation.debug` | 调试指令组 |
| `cultivation.debug.vein` | `/cultivation debug vein` |

</Note>
