# 术语表

本模组的词汇取自修真小说，并赋予其具体的机制含义。 下表列出各词在*本模组中*的确切所指，并附英文原文以便对照。

## 修炼之道

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| **灵气** | Qi | 天地灵力，亦是一切进度的通货。每次晋阶与突破都以其买单。 |
| **修真 / 修炼** | Cultivation | 炼化灵气以求长生的修行。 |
| **境界** | Realm | 自炼体至炼虚的七重大境。 |
| **阶段** | Sub-stage | 每重境界内的四级：初期、中期、后期、巅峰。 |
| **晋阶** | Advancement | 推进一个阶段的短仪式，需区块灵气 200、底端 8 秒。 |
| **突破** | Breakthrough | 由巅峰迈入下一境界的大仪式，需 750 区块灵气、24 秒起，并招来天劫。 |
| **天劫** | Tribulation | 天道对突破的回应：每 6 秒仪式进度落下一道雷，足以致命。 |
| **心魔劫** | Heart-Devil Trial | 阴阳偏执过甚者所面对的替代考验，攻的是道心而非气血。 |
| **道心** | Composure | 心魔劫所消磨的心境池，每次尝试重置；一旦见底，仪式失败。 |
| **走火入魔** | Qi Deviation | 道心崩溃的后果 —— 仪式失败并跌落一个阶段。 |
| **业力** | Karma | 因斩杀同道而记下的账，天道会在下次天劫时一并清算。 |
| **气息** | Aura | 修士外放的可见灵气 —— 境界定其色与浓密，阶段定其大小；打坐另有一种向内汇聚的气息。见[修为气息](/zh/auras/)。 |
| **称号** | Title | 凭修行挣来的纯装饰名号，悬于头顶、缀于聊天，亦上排行与名册。见[称号](/zh/titles/)。 |
| **存档** | Profile | 一个账号最多保留的三名修士之一。境界、种族、大道、天赋与功法随之转换；宗门、洞府、阵法与道侣归于账号。见[修炼存档](/zh/profiles/)。 |

## 灵气与地脉

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| **打坐** | Meditation | 盘膝汲取脚下区块的灵气。偏离落座点超过 0.35 格，进行中的仪式即告作废。 |
| **灵脉** | Spirit Vein | 每区块一处的灵气池，被汲取则减、随时间回复，由世界种子确定生成。 |
| **灵脉（丰沛）** | Rich vein | 约 3% 的区块，池量更大，回复 ×1.25。宗门大殿可设立的最低脉品。 |
| **龙脉** | Dragon vein | 最稀有的一档，约 0.3% 的区块，回复 ×1.6 —— 值得为之开战的土地。 |
| **灵核 · 玄核 · 神核** | Spirit / Profound / Divine Core | 生物掉落，吸收可立得一笔灵气。每次击杀至多掉落一枚。 |
| **聚气符** | Qi Gathering Talisman | 随身携带即可提升打坐时的灵脉汲取速度，无需握在手中。 |
| **灵石** | Spirit Stone | 维护洞府所用的通货，由击杀与挺过天劫掉落。 |

## 大道

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| **大道** | The Dao | 承载元素亲和与阴阳之衡的那一页。 |
| **五行** | Wu Xing | 金木水火土，循环相克。 |
| **暗环** | Shadow ring | 另外五种幽暗元素构成的第二条相克之环；跨环相遇则互不克制。 |
| **阴阳之衡** | Yin-Yang balance | 随行止、所处之地与种族天性而漂移的一条轴。居中可得全面加成。 |
| **偏执** | Lean | 偏离中位的程度（0–1）。达到 0.5 便以心魔劫取代雷劫。 |
| **魔道** | Devil Path | 极阴修士所走之途，另有战斗增益与斩杀玩家掠夺灵气之能。 |
| **正道** | Righteous Path | 极阳一侧的对应，专克魔道。 |

## 功法与法宝

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| **功法** | Technique | 主动施展的法术，受境界、灵气消耗与冷却三重限制。 |
| **秘籍** | Manual | 可拾取的典籍，传授一门功法或一个天赋节点。自 0.7.4 起，内置各法皆设有 `Requires-Unlock`，故仅有境界从来不够 —— 秘籍是求得一门功法的四途之一。 |
| **天赋树** | Skill tree | 九条分支、117 个节点的环形天赋树。晋阶 +1 点，突破 +3 点。 |
| **本命法宝** | Life-Bound Treasure | 与你本人相系的兵器或护甲，随使用而升级。 |
| **炼丹** | Alchemy | 以修炼之核炼制丹药，可御雷劫、抗心魔或助推突破。 |
| **炼器** | Refinement | 以天劫之雷淬炼兵器，赋予其道之元素与一至九阶的品阶。失败可致兵器尽毁。 |
| **灵兽** | Spirit Beast | 驯服或孵化的伴生兽，会随你一同修炼自身境界。 |

## 红尘世间

| 术语 | 英文 | 含义 |
| --- | --- | --- |
| **宗门** | Sect | 玩家公会，设宗主、长老与门规，默认上限 12 人。 |
| **宗门大殿** | Sect hall | 宗门占据的区块，须设于丰沛灵脉之上，全宗灵气加成由此而来。 |
| **碑文** | Inscription | 镌刻于大殿之上的功法秘籍，只要大殿仍在，便传于全宗弟子。 |
| **光柱** | Hall beacon | 立于已占大殿之上、任何人可见的一道光。未悬旗帜时燃着灵脉本色。 |
| **旗帜** | Banner | 宗门悬于大殿之上的颜色 —— 四象、金庭或玉台 —— 由宗主或长老择定，并为大殿在世界地图上的标记着色。见[宗门](/zh/sects/)。 |
| **阵法** | Formation | 布于区块之上的阵，可增益己方打坐、削弱外人灵气，或困伤来犯者。 |
| **洞府** | Cave Abode | 个人居所，其灵泉即便离线亦按真实时间积攒，需回洞府领取。 |
| **闭关** | Seclusion | 于洞府中以时间换取灵气，每次上限 24 小时。 |
| **宗门攻伐** | Sect war | 攻取敌宗大殿的围攻战；在时限内守住阵地，灵脉便易主。 |
| **斗法** | Duel | 双方自愿、以灵气为注的比试，即便在关闭 PvP 的世界中亦可进行。 |

<Note kind="tip" title="关于用字">
  本站所用术语与模组内置的简体中文语言包保持一致，因此你在游戏中看到的词，与此处所读到的完全相同。
</Note>
