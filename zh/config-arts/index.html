功法配置

mods/Siren_Cultivation/Arts/ 中的七份文件涵盖修士所修习、所炼制、所淬炼、所认主的一切 —— 他所行的大道、他所施展的功法、传授这些的秘籍、他在炼丹中所炼的丹药、他所承受的炼器、他的本命法宝，以及他的灵兽。

这是最大的一组配置。其中几份文件承载的是数组而非单纯的数值 —— Techniques、Manuals 与 Beast-Species 都是开放的表，你尽可往里添加自己的条目。

大道配置

各元素大道、阴阳之衡、天候共鸣、正魔两途之分，以及业力，位于路径 mods/Siren_Cultivation/Arts/DaoConfig.json。它们在实战中的作用见大道与业力。

功法配置项

每一门主动修炼功法背后的规则集，位于路径 mods/Siren_Cultivation/Arts/TechniqueConfig.json。各门功法的效果见功法。

配置项默认值说明
"ConfigName""Technique Config"此配置文件的名称。
"ConfigVersion"1你为此插件加载时的当前版本。
"Techniques-Enabled"true整套功法系统的总开关。为 false 则一次性禁用每一门功法，与各自的规则无关。
"Description-Techniques"一段解释上述数值的长字符串。重述此开关凌驾于下方 Techniques 数组中的每一条之上。
"Techniques"一个含九条内置规则的数组（见下）。每门功法一条。每条的 Id 须匹配某个功法 id，管理器才会将其作为覆写施加。
"Description-Technique-Rules"一段解释上述数组的长字符串。记载功法规则的每一个字段，以及「一步千里」的距离参数。

Techniques 数组中的每一条采用如下结构。

配置项默认值说明
"Id"""须匹配一个已注册的功法 id，此条才会作为覆写生效。
"Enabled"true仅开关这一门功法。
"Dao-Specific"false若为 true，唯有所择之道为 Required-Element 的修士方可施展。
"Required-Element"""此功法所锁定的 DaoElement 名称。仅在 Dao-Specific 为 true 时有意义。
"Elements"""以逗号分隔的 DaoElement 列表，标示该功法所带的属性，用作元数据与风味。
"Damage-Type"""伤害类功法所用的 DamageCause 资产 id。留空则效果回退为 PHYSICAL，而大道战斗过滤器仍可能将其重新转为施法者自身的元素。
"Requires-Manual"false为 true 时，此功法在被秘籍传授之前无法施展。内置九法默认皆未设此项。
"Unlock-Realm""QI_CONDENSATION"使用它所需的境界，以枚举名表示。
"Qi-Cost"0.0每次使用所耗的存蓄灵气。
"Cooldown-Seconds"0.0两次使用之间的真实时间冷却。
"Params"[]一个 Key／Value 对的数组，承载该功法专属的数字，如此一门功法可以自行添加旋钮而无需改动配置的结构。

秘籍配置

可拾取、能永久传授一门功法或一个天赋节点的典籍，位于路径 mods/Siren_Cultivation/Arts/ManualConfig.json。见秘籍。

配置项默认值说明
"ConfigName""Manual Config"此配置文件的名称。
"ConfigVersion"1你为此插件加载时的当前版本。
"Manuals-Enabled"true整套秘籍系统的总开关。
"Manual-Consumed-On-Use"true阅读秘籍是否将其消耗。阅读一本你已知晓的秘籍会被拒绝，且无论此项如何都不消耗。
"Manual-Tribulation-Drop-Chance"0.04秘籍掉落的概率，每挺过一道天劫落雷判定一次 —— 因此一场漫长的仪式便是许多次判定。
"Manual-Demonic-Cultivator-Drop-Chance"0.12玩家斩杀角色 id 列于下方的 NPC 时，秘籍掉落的概率。
"Manual-Demonic-Cultivator-Npc-Roles"""以逗号分隔的、算作魔修的 NPC 角色 id。默认为空是有意为之：角色 id 因世界与区域而异，随便塞一个猜测要么毫无作用，要么在错误的怪物身上触发。
"Manual-Player-Kill-Drop-Chance"0.02斩杀另一名修士时，从其身上震出一本他自己所知之法的秘籍的概率。刻意压得极低 —— 对受害者而言这是实打实的损失。
"Manuals"一个含五本天赋节点秘籍的数组（见下）。掉落表，以及从功法或节点反查回传授它的那本秘籍的索引。
"Description-Manuals"一段解释上述数值的长字符串。解释秘籍传授什么、消耗规则、全部三处掉落来源，以及掉落的秘籍是按 Weight 从表中挑选的。

Manuals 数组中的每一条采用如下结构。

配置项默认值说明
"ItemId"""该秘籍物品的资产 id。
"TechniqueId"""阅读它所传授的功法（若有）。仅对规则中 Requires-Manual 为 true 的功法有意义。
"SkillNodeId"""阅读它所解锁的天赋树节点（若有）。该节点的前置要求仍须遵守，但其天赋点消耗被无视。
"Weight"1.0在掉落表中的相对权重。0 表示它永不自行掉落，只能由管理员或其他模组放置。
