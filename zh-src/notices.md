### 屏显通告

要紧的时刻如今**跃上屏幕**，而不再从聊天栏里一滚而过。突破新境时，一行大字接管整个屏幕 —— 理当如此 —— 且**九个区块之内的每一名修士都会得知**。突破是发生在这片天地间的事，不只属于你一个人。v0.7.0 新增。

每一条通告都是对聊天栏原有信息的*叠加* —— 大字淡去之后，没有任何内容就此失落。

* * *

#### 标题与通知

两种载体，各承其重：

| 时刻 | 载体 |
|:---|:---|
| **突破**新境 | 全屏标题，六秒 —— 附近每人另见一行小字 |
| 阶段**进阶** | 全屏标题，四秒 |
| 跌出阶段的**倒退** | 全屏标题 —— *修为倒退* |
| 创立、加入、离开[宗门](/cultivation/sects/) | 全屏标题 —— 下方附**宗门格言** |
| 解锁[天赋节点](/cultivation/skilltree/) | 角落通知 |
| [本命法宝](/cultivation/lifebound/)升级 | 角落通知 |
| [种族](/cultivation/races/)变更、天赋重置 | 角落通知 |
| 仪式开始 —— 突破、进阶、[炼器](/cultivation/refinement/) | 角落通知，作警示样式 |

入宗与离宗标题下的那句格言，是一个宗门里唯一真正出自宗主之手的一行字，说在它最有分量的时刻。**被逐出**的玩家刻意不会看到它 —— 被刚刚驱逐你的宗门递上它的格言，读来无异于奚落。

有两个时刻无论这些开关如何设置，都保有各自专门撰写的标题：**走火入魔**与**心魔劫**。[天劫](/cultivation/tribulations/)落雷在此处则完全不显 —— 雷是连环落下的，一雷一题只会闪成频闪。

#### 突破的传扬

有人突破时，**九个区块**半径内的每一名修士都会看到一行小字，写明其人与其新入之境。该半径是纯粹的距离，而非按已加载区块计算，且由服主调校：

| 配置项 | 默认值 | 说明 |
|:---|:---|:---|
| `Breakthrough-Title-Radius-Chunks` | 9 | 一场突破传扬多远，以区块计。取值收束于 0 至 32。**设为 0 则所有突破皆为私事。** |

#### 写给服主

| 配置项 | 默认值 | 说明 |
|:---|:---|:---|
| `Notice-Titles-Enabled` | true | 本系统的全部全屏标题。 |
| `Notice-Notifications-Enabled` | true | 全部角落通知。 |

两项都在根目录 `Config.json` —— 见[核心配置页](/cultivation/config/core/) —— 且都不触碰聊天栏文字：关掉一种载体从不会让事件静音，只是改变它落地的响度。
